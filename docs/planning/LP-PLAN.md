# HOTEL BUSTEL LP制作プラン

作成日：2026-10-26（日本時間）

制作計画とヒーロー用生成画像案に基づいてLPを実装済み。ユーザー指定により実装後の確認は行っていない。公開は未実施。実装記録は `../IMPLEMENTATION.md`。

## 1. コンセプト

**横浜の街へ。伊勢佐木町を、旅の拠点に。**

京急黄金町駅から徒歩5分、伊勢佐木町6丁目、全20室という具体的な情報を中心に、客室の実写と明快な料金案内で宿泊判断につなげる。

写真にある紺のカーテン・白い寝具・木目・畳、外観看板の紺をデザインの根拠とする。高級ホテルを想起させる装飾や、裏付けのない品質・最安値の訴求は加えない。

## 2. 参考サイトから取り入れること

### Partire Takasago Hotel

https://partire-takasago-hotel.pages.dev/

ブラウザで閲覧確認済み。大きなエントランス写真、軽いヘッダー、右側の予約導線、Price → Rooms → Info → Access → Contactという情報順を参考にする。壁・照明・ガラスなど建築の細部を切り取る写真表現も参考とする。

### リベール博多駅前ホテル

https://liveil-hakataekimae.pages.dev/

ブラウザで閲覧確認済み。木や緑、ガラスを取り入れた写真、抑えた色数、日本語コピーと小さな英文、十分な余白、客室ギャラリーと写真番号を参考にする。

両サイトの写真や文章は流用しない。BUSTELでは実際の客室写真から配色を決め、料金を横長の一覧、客室を大小の写真で見せる構成にする。

## 4. 画面構成

### 01 ヘッダー・ヒーロー

- PC・スマートフォンとも、デバイスのブラウザ表示領域いっぱいのヒーローにする。画像をヒーロー全面へ敷き、上下左右に余白を設けない。
- ヘッダーは画像の上に重ね、左にHOTEL BUSTEL、右にメニューボタンだけを置く。客室・料金・アクセス・ご予約はメニューを開いたときに表示する。
- 写真と色面の分割や、スマートフォンで写真とコピーを別々の段にする構成は採用しない。
- 写真は生成した `public/images/generated/bustel-hero-concept-v1.png`。白壁・木・ガラス・葉影の接写で、実在しない客室や設備の全景を作らない。
- メインコピー案：`横浜、伊勢佐木町に泊まる。`。写真上の左下寄りに小さめに配置する。画面幅に応じて自然に2行までに収める。
- ヒーローの文章はホテル名とこの短いコピーを中心にする。補足説明、徒歩分数、客室数、料金は次のセクション以降へ移す。
- 下端には小さなスクロールの目印。予約の常設ボタンはヒーローを抜けてから表示し、初期画面では写真の面積を確保する。ヒーロー表示中もメニューから予約先へ進める。
- 生成画像の端に読める大きさで `イメージビジュアル（AI生成）` と表示する。
- 画像はabsolute配置のimgまたはpictureで全面に敷き、width/height 100%、object-fit: cover。PCとスマートフォンでobject-positionを調整し、縦画面でも木・ガラス・葉影が残る位置を選ぶ。
- 高さは100dvhを基本とし、未対応環境は100svh・100vhへフォールバック。ヘッダー分を高さから引かず、画像をヘッダーの背後まで連続させる。スマートフォンのアドレスバー表示変化にも追従する。
- テキスト周辺だけに薄いグラデーションを重ねてコントラストを確保する。上下端のUIはsafe-areaを考慮して画像の内側に置く。

### 02 料金：横長の料金台帳

- ヒーロー直下に `京急黄金町駅 徒歩5分`・`全20室` の短い基本情報を置き、続いて平日・土日休日の金額を比較できるようにする。
- PCは2列、スマートフォンは2行。余白と罫線で区切り、数字と「1室」を主役にする。
- 表示原稿：`平日 9,000円／1室`、`土日休日 15,000円／1室`。
- 提供情報にない「〜」「税込」「1名あたり」「1泊」は勝手に加えない。税・宿泊単位・対象人数は掲載確定時の確認事項。
- `ご希望の日程・人数での料金と空室状況は、各予約サイトでご確認ください。` を添える。LP内に未連携の空室検索UIを置かない。

### 03 客室：実写を中心にした写真構成

- `IMG_3284.JPG` のベッドが並ぶ写真を大きく掲載し、`IMG_3281.JPG` の畳と布団の写真を少し小さく配置する。
- PCは写真の上辺をずらして空間の違いを見せる。スマートフォンは縦に並べ、写真を十分な大きさで表示する。
- 見出し案：`旅の時間に、ひと息つける場所を。`
- 写真の説明は `ベッドを備えた客室の一例`、`畳スペースを備えた客室の一例`。正式な客室タイプ・定員・専有面積の断定は保留。
- `IMG_3280.JPG` の洗面台、`IMG_3283.JPG` の浴室を小さな補助写真に使用。写真の設備を全室共通とは記載しない。
- ギャラリーには前後ボタン・写真番号・拡大表示。自動切替を必須とせず、閲覧者の操作を優先する。

### 04 ご滞在案内：フロントをイメージした一覧

- `IMG_3282.JPG` の入口写真と、基本情報の罫線付き一覧を組み合わせる。
- 店舗名：HOTEL BUSTEL
- 電話：045-315-7155、リンク先 `tel:0453157155`
- フロント：10:00〜22:00頃（平日・土日祝共通）
- 定休日：なし
- 客室数：20室
- 楽天トラベル・Trip.comの両方にチェックイン14:30〜、チェックアウト12:00の掲載を確認。楽天には最終チェックイン22:00の記載もある。フロント対応時間とは別の行で扱い、公開時に最新情報を再確認する。
- 朝食・駐車場・決済・荷物預かりなどは、必要な場合だけ最新の公式運用を確認して追加する。予約サイト間で異なる決済案内は転記しない。

### 05 アクセス：黄金町駅からの来館を支える

- `京急黄金町駅から徒歩5分` を大きく表示。
- 住所：神奈川県横浜市中区伊勢佐木町6−140−7。
- 地図と「Googleマップで経路を見る」を配置。埋め込み地図は遅延読み込み。
- 徒歩ルートを独自に描く場合は実際の経路を確認する。写真や根拠のない曲がり角案内、観光地までの所要時間は加えない。
- 外観の `IMG_3509.PNG` は現地で入口を見つける手がかりとなる候補。ただしTrip.com透かしがあり、まず手元の透かしなし素材を優先する。使用する場合は出所・使用条件を確認し、透かしを消さない。

### 06 ご予約・お問い合わせ

- 紺色の大きな面に、楽天トラベルとTrip.comを同じ強さで並べる。
- ボタン文言：`楽天トラベルで空室を確認`、`Trip.comで空室を確認`。
- 電話番号とフロント対応時間を近接させる。電話の用途は `お電話でのお問い合わせ` とし、電話予約対応を推測しない。
- スマートフォンの固定下部には「空室・ご予約」と電話ボタンを、ヒーローを抜けた後に表示する。予約ボタンから同ページ内の2つの予約先へ移動し、迷わず選べるようにする。

## 5. GSAP・Lenisの動き

| 場所 | 動き | 初期設定の目安 |
| --- | --- | --- |
| 初回ヒーロー | 写真のわずかな縮小とコピーの行単位表示 | 画像1.04→1.00、約1.2秒。コピー24px→0、0.7秒 |
| 見出し | 下から軽く浮かび、不透明度が上がる | 16〜24px、0.6〜0.8秒。初回のみ |
| 料金 | 罫線と文字を順に表示 | 0.5〜0.7秒。金額は初めから正しい数値を表示 |
| 客室写真 | PCのみ、写真枠内でゆっくり移動 | 全体で20〜32px以内。ScrollTrigger連動 |
| メニュー | 背景とリンクを短く順に表示 | 約0.3〜0.4秒 |
| 予約ボタン | 色・矢印の小さな移動 | 約0.2秒。キーボードフォーカスも明示 |

- GSAPは登場演出、ScrollTriggerは表示位置との連動、LenisはPCのホイール操作を整える役割に分ける。
- LenisのrafはGSAP tickerで一元管理し、LenisのscrollイベントからScrollTrigger.updateを呼ぶ。重複するrafループは作らない。
- スマートフォンのタッチ操作は標準挙動を優先し、syncTouchは使わない。
- prefers-reduced-motionではパララックス・拡大・段階表示とスムーズスクロールを止め、情報をすぐに表示。
- 長いローディング、スクロールの強制停止、横スクロールへの強制変換は加えない。
- JavaScriptが使えなくても、文章・料金・写真・予約リンクは表示される設計。
- メニューと画像モーダルはEscで閉じられ、フォーカスを開いたボタンに戻す。背景スクロールは開いている間だけ停止。

## 6. 実装の構成案

現状はAstroの初期ページ。package.jsonにAstro・GSAP・Lenisがあり、これを利用する。

- `src/data/hotel.ts`：名称、料金、電話、住所、予約URL、フロント時間、写真と出所を集約。
- `src/components/`：Header、Hero、Price、Rooms、StayInfo、Access、Reservation。
- `src/styles/global.css`：配色・文字・余白と全体設定。各コンポーネントに固有スタイルを置く。
- `src/scripts/motion.ts`：GSAP、ScrollTrigger、Lenis、動きを減らす設定。
- `src/pages/index.astro`：日本語の見出し階層とページ構成。
- 実写はAstroの画像処理で適切なサイズにする。ヒーローのみ優先読み込み、下部写真は遅延読み込み。生成PNGは実装時にWebP/AVIF化と容量調整を行う。
- タイトル案：`HOTEL BUSTEL｜黄金町駅徒歩5分・横浜 伊勢佐木町のホテル`。
- Hotel構造化データには確認できた名称・住所・電話・客室数を使用。料金Offer、星評価、口コミ集計は追加しない。canonical・OGのURLは公開先が決まってから設定。

## 8. 掲載情報と確認事項

ユーザー提供情報を優先する。次の未確定事項は実装全体を止める条件ではなく、確定するまで表現を限定する項目。

- 9,000円・15,000円の税込／税別、1泊の金額か、対象人数・客室タイプ、休日の適用区分。
- 各実写に対応する正式な客室タイプと、部屋ごとの設備・定員。
- 正式ロゴの元データ。外観写真内のシンボルを推測で再制作しない。
- 公開先URL。未確定URLをcanonicalやOG画像URLに入れない。
